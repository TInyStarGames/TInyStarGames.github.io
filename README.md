# TinyStarGames Website

Official static studio website for TinyStarGames.

## Features
- Responsive studio design
- Games catalog generated from `games.js`
- Hover previews and click-to-open game details
- Roblox play links
- Screenshot gallery support
- Tutorial/guide links
- Mobile navigation
- Zero backend dependencies

## Adding a game
Add another game object to `window.TINYSTAR_GAMES` in `games.js`. Each entry can include a title, development status, description, Roblox play URL, cover image, screenshots, and tutorial links.

## Hosting
Designed for GitHub Pages at the organization site repository `TInyStarGames/TInyStarGames.github.io`.
